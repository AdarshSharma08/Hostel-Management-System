# Hostel Management System 🏨

A Python-based Hostel Management System developed as a B.Tech CSE (AI/ML) mini project.

## 📌 About the Project

The Hostel Management System is a desktop application designed to help manage hostel student information and complaints through a graphical user interface.

The application is built using Python, CustomTkinter, and SQLite.

## 🛠️ Technologies Used

* **Python** — Application logic
* **CustomTkinter** — Graphical user interface
* **SQLite** — Database management
* **Git and GitHub** — Version control and project hosting

## ✨ Features

* Graphical user interface
* Student login
* Admin login, if implemented
* Student information management
* Complaint submission
* Complaint categories, including Electricity, Water, Cleaning, Internet, and Other
* Complaint status tracking
* SQLite database integration
* Password hashing

*Only features implemented in the current version should be listed.*

## 💻 Requirements

* Python 3
* CustomTkinter

## 🚀 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/AdarshSharma08/Hostel-Management-System.git
```

### 2. Open the Project Folder

```bash
cd Hostel-Management-System
```

### 3. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run the Application

```bash
python main.py
```

## 🗄️ Database

The application uses SQLite to store its data.

The database may be created automatically when the application runs, depending on the implementation.

Do not upload real student information or confidential account details.
